# Codex Math 验证

## 实现与范围

入口为 setup-math/run-math。setup 自动创建并核验三个同项目 Codex 任务，询问初始模型与推理强度，创建后保留用户自行修改。run 包含启动讨论、材料核对、上下文准备、派发、等待与预算、按轮接纳、收尾理解七个阶段。

## 本地检查

本地检查覆盖技能结构与链接、Node 与 Python 回归、状态校验、证据归档和恢复规则。最近一次检查结果与命令见 [检查记录](checks.md)。

## 限制

本地回归不等于真实宿主端到端验证或数学审核。尚未通过真实宿主创建、绑定、派发三个研究任务的完整验收。目标宿主首次使用须按 [核验清单](target-host-checklist.md) 检查真实创建回执、绑定恢复、模型修改保留及完整结果归档。
