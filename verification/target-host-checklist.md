# 目标宿主首次使用核验

本项目尚未完成真实宿主端到端验证。以下需在目标宿主按实际工具回执核验，不能以本地回归替代。

1. 首次 setup：先询问模型/强度、分工预算与本项目数学接纳授权，自动创建三个同项目 local 任务；全部具有真实 ID，初始化仅待命，无数学派发。
2. 重跑 setup：复用三项 ID；手动修改其中一项模型后，再 setup/run 不覆盖修改。
3. 创建中断：保留成功项；不确定 creating 必须先核对，不能重复创建或仅按标题绑定。
4. 普通聊天/错误项目/自身 ID/临时 clientThreadId：不得作为有效研究池。繁忙或读取失败不触发自动替换。
5. 首轮研究：完成真实目标及首轮路线讨论并核对基线后再派发；prompt 自包含，独立实验目录；共享事实仅由 Main 维护。
6. 回收：wait_threads 及时唤醒，read_thread 完整读取对应 task ID；缺正文、报错、审批或需输入不登记 returned。sending 起算期限，超时收尾不重发。
7. 有数学增量：原始记录完整归档、独立原生审核，接纳后发布事实文章；任务作者不得自审。无增量、失败与中断保留真实边界。
