# Commit 后维护完整事实文章

读取 [文章接口](../shared/ARTICLE-WORKFLOW.md) 及 [文章内容规范](../shared/ARTICLE-CONTENT.md) 的“增量维护”和“材料与审核复用”。新增数学必须先有本轮真实 Commit 与增量审计收据；用户要求整理已发布账本时，使用接口的纯编辑修订入口，复用原接纳依据。

每轮落实新结果与旧结果的关系及主要陈述位置，同步受影响的总览、引用和开放边界；批次结束按内容规范做整体整理。完整保留有效数学，不以全文原样追加代替整合。整理引起的多处来源合并保留稳定结果身份和来源记录，供后续按需建图复用。

保留既有来源、覆盖与审核定位；每轮仅更新变化项和受影响依赖，替换证明后逐结论核对保留性。以冻结旧事实文章和已接纳增量为依据，维护一篇完整正文：有效定义、约定、假设、结论、必要证明及逻辑连接全部落实，更新受影响章节和依赖，处理撤回与冲突，不靠历轮增量或外部对话才能读懂。开放问题、猜想、条件性结论和计算证据明确标注。过程记录放档案；正式论文的选题、润色和排版另由 write-complete-math-article 处理。

允许重新组织和衔接文章，保持已接纳的数学内容与条件。发现证明缺口或需新数学判断时暂停发布，交 Main 优先修订（含短证明补齐），按文章接口 start --repair-of 另存更正增量；Sol 审核和关联更正 Commit 后再维护全文。数学修订不能藏在编辑整合中。

在文章接口规定的整合分级下运行 article-packet 和 update-article：Main 能够确认含义与完整性保持时直接维护核对，包含已接纳内容的替换、措辞调整和章节整理；需要第二视角或不确定时调用 review-math-article 的 article-integration。不因改了旧文就自动增加审核。审核输入先看变更索引，再按影响展开正文；两条路径均检查全文完整性，不重复接纳数学。具体条件、字段与命令只以共享文章接口为准。

整合核对通过后立即 publish-article，发布完整事实文章并交 Main 同步事实索引；有预算的下一轮可使用该文章。本次文章维护到此完成，不自动调用 to-map、map-review 或创建地图待办。整批研究结束后由研究入口交 understand-research；若本调用来自理解环节中的文章整理，则返回该理解会话，不递归启动新会话。用户随后选择建图时，以整理后准确文章另行调用 to-map。旧地图只提供带来源版本的导航。

文章维护失败恢复文章步骤；文章尚未发布时可用新 ARTICLE_ROUND 修订表达、沿用同一 Commit。文章发布后保持固定；地图审核有内容问题时由 Main 优先按原文修正提取，保存新地图 ROUND 并交原独立 reviewer 核对变化及影响；可选表达建议不强制修订，不阻塞地图发布。地图修订不增加推理轮。原文数学问题则登记失效、暂停受影响推理并基于当前文章另存更正增量。审核完成按轮次合同直接接续，不等定时 heartbeat。旧 v1 历史审查包按旧共同发布收据恢复。
