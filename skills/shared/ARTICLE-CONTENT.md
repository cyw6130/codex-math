# 完整事实文章：汇编、维护与审核复用

本文是文章内容维护的共同规范。首次历史汇编读取“首次汇编”；日常 Commit 后读取“增量维护”；写作者和审核者共用“材料与审核复用”。轮次与接纳时序仍以 [轮次合同](ROUND-WORKFLOW.md) 和 [文章接口](ARTICLE-WORKFLOW.md) 为准，本文不增加接纳或发布阶段。

## 首次汇编与已有基线接续

已有有效 workspace 时直接核对并恢复；已有准确完整文章及适用审核时复用交付，不重写、不重新盘点已经闭合的来源，也不补造历史 Attempt。登记初始化不是重新接纳历史数学。

只有缺少完整文章或用户明确要求重建时，先确定用户已指定的数学范围及待核对来源。区分尚未检查的材料和已经确认的数学缺口，继续调查前者。以覆盖最广的成熟母稿为底本，结合准确修订、有效结果索引和必要原始材料；没有成熟文章才从已有定义、约定、目标、结果和开放边界组织起始全文。来源多不等于已覆盖全部结果。

先抽查不同类型的来源，尽早发现缺证明、符号冲突和覆盖范围问题。旧绝对路径失效时，查当前项目与来源清单并核对内容身份，记录迁移对应。不可因路径失效就宣布证据遗失，也不可因找到同名文件就认定内容相同。

按来源成组恢复正文，再逐项核对范围内的有效结果。主定理完成不会自动涵盖历史独立引理、局部条件证书、反例和计算。处理状态使用收入、同一结果合并、准确修正版替代、已有依据的撤回、待解决；每项说明准确陈述及对应范围。不同来源的索引可能重叠，不把条目数相加当定理数。历史 Attempt 或地图状态本身不构成接纳依据。

产物为完整候选正文、来源/覆盖定位与可复用审核；交 review-math-article 的 whole-article、purpose=initial-facts 检查准确全文忠实性、范围覆盖和跨章节一致性。默认最多三轮定向修订；问题保留稳定编号，重审改动及影响范围。发现需新假设、新对象身份或实质新证明的问题时如实留缺口，返回调用方，不借初始化派发新研究或把缺口算作完成。

初始化审核报告至少写 scope=whole-article、purpose=initial-facts、verdict=pass/needs_revision、准确文章路径与哈希、审核输入清单及哈希、真实作者/审核者身份、复用项、新检查项、must_fix 和未解决项。只有 must_fix 与未解决项均为空且指定范围覆盖闭合才 pass；原始报告及修订档案保留在初始化目录。

审核通过后由 initializing 按既有授权登记准确文章和地图；审核报告不是共同发布收据。本文不触发派生论文写作。

## Commit 后增量维护

从冻结旧全文、已接纳增量及旧覆盖记录进入，只更新变化来源、受影响章节和对应覆盖项；未变的部分保留。没有已有覆盖表时为本次变化建立最小定位，不强迫每轮重新盘点全部历史，也不声称历史全量盘点已经完成。

正文以数学内容组织：定义、假设、陈述、必要证明、计算及开放边界完整可读。过程身份和处置表放档案，正文中的依赖写成定义、章节或准确引用。不能靠研究日志链接代替必要证明。

每轮在现有覆盖记录中说明新结果对旧内容的关系：补充、加强、同一结果合并、准确替代或关闭问题，并落实到受影响章节。按数学主题安置内容；只有形成独立主题时才新增章节。逐字保留旧文并追加全部增量，不足以证明整合完成。同步检查总览、主要结论、阅读路线与开放边界；未受影响时不必改写。旧问题已有答案时写成当前结论的准确引用，并保留仍未解决的范围。

每个可独立引用的结果有一个主要陈述位置，保留完整条件、结论和必要证明，其他位置按需概述或引用。合并依据是对象、条件和结论的一致性，不按标题相似、篇幅或条目配额裁剪；更强定理不能自动替代旧结果的不同适用范围。独立有用的另一证明、特例、计算证书和反例可以保留，说明其用途与主结果的关系。沿用来源—正文—审核记录保留被合并位置、稳定 ID 和理由。

引用使用明确的命名空间与稳定锚点。允许节内公式编号，但跨节引用须带章节，不能把局部重复编号本身判作错误。结果名、章节名和引用显示文字不得造成歧义；编号与锚点调整同步更新引用。机械检查只发现悬空或重复定位，不判定数学同一性。

研究批次结束，或用户要求整理账本时，检查累积内容的主题编排、重复陈述、总览及陈旧开放边界，按影响完成一次整体整理；不因此开启新研究轮。可将同一权威全文组织为主线、技术材料与当前开放问题，结构按材料选择，不强制拆成多份权威文章。日常局部维护与批次整理共用上述覆盖记录及整合分级，不新增每轮全文数学重审。已发布文章的纯编辑整理走文章接口的 editorial-packet / publish-editorial，保留原数学接纳依据。

合稿和修订重点检查：

- 同名算子、空间或归一化先比定义，只有既有依据给出转换才能合并；局部符号可保留独立作用域。旧“尚未证明”按当时方法或范围定域，不覆盖较新结论。
- 每份关联证明按其实际支持的陈述和前提使用，不能将多份来源机械视为同一命题的多份证明。替换证明后逐项核对原命题的全部结论仍有证明，防止定向修补造成回退。
- 定义先于使用，跨篇引用落到合稿内的准确位置；转换格式、改编号只作用于已识别的引用，核对公式、文献标签和数学表达式。位置使用显式锚点或绑定版本的行号。

按 [文章接口](ARTICLE-WORKFLOW.md) 分级核对：Main 根据实际内容判断整合忠实性和完整性；能可靠核对的编辑与已审增量落实直接维护，需要第二视角或仍有疑点才做独立 article-integration。文字形状、改动长度和章节移动本身不决定审核级别。本文的全文完整性要求不新增每轮全文数学重审。维护中新发现的数学判断不能夹入已接纳增量；先交 Main 分诊并按文章接口的关联修订通道处理；修订数学经 Sol 审核和更正 Commit 后再整合，保留原 Commit 历史。

## 材料与审核复用

| 既有依据 | 可以复用 | 本次仍需检查 |
| --- | --- | --- |
| 准确版本的独立全文数学审核 | 未变且来源、条件与依赖仍有效的陈述和证明 | 新增内容及合稿后的符号、依赖和范围衔接 |
| 局部数学审核 | 报告明确受审的数学范围 | 缺失上下文、定义和跨稿兼容 |
| 地图/文本提取忠实性审核 | 已核对的来源与提取内容关系 | 原来源是否完整收入、正文是否含必要证明 |
| 已关闭问题及对应复审 | 准确修订的关闭依据 | 本轮改动是否重新影响该问题 |

全文哈希改变不等于全部旧审核失效；相同片段也不保证其依赖仍有效。检查实际陈述、证明、约定、量词、来源撤回及依赖变化。复用必须说明依据和范围，不能将局部 pass 拼作新全文 pass。新增数学的审核仍由 fact-increment 承担。

用一份可复用的来源—正文—审核定位记录支撑检查。沿用已有清单格式；没有格式时，每项记录：稳定结果标识/准确陈述，来源路径与哈希/定位，旧新正文的版本与位置，处置及理由，审核报告路径/哈希/范围，改动与受影响依赖。定义、开放问题、计算证据和已证命题分别说明；覆盖状态不代表证明状态。日常只追加或更新变化项，审核报告的存在不自动证明适用于当前内容。

材料归档与交接：

- 初始化汇编：来源、覆盖及复用记录随候选保留；最终报告绑定文章与审核输入的准确哈希，分别列复用项、新检查项和未解决项。初始化依文章接口保存真实 provenance；无需伪造 native Commit 收据。
- 本轮增量：把变化项、依赖影响和审核依据定位写入现有 round-summary 的结构化部分，随总结和必要原始来源作为 finish Evidence 冻结；无需另一份叙事总结。prepare 的 review-focus.json 只是阅读索引，不能自动识别数学影响或替代覆盖记录。
- Commit 后整合：逐项落实与旧新正文定位写入轻量 CHECK.coverage 或独立 verdict 的实际核对说明，绑定准确文章包；原始已接纳材料从冻结 accepted 包读取。新增的外部数学依据若为整合所必需，应交回增量审计，不能以编辑说明接纳。

独立审核者先按变更及复用记录定位，检查必要原文和证据；有冲突或范围不清则扩大检查。只有范围覆盖闭合、必修问题关闭且版本绑定有效，才报告相应审核完成。机器哈希和结构检查不证明数学正确或语义覆盖。

## 为后续形式化准备文章

沿用现有稳定结果标识、主要陈述位置与来源记录，不另造一套数学事实。写作和理解整理时明确对象的底域、参数范围、量词、符号作用域、构造与约定；关键中间引理有可独立引用的完整陈述，证明中直接使用的结果和外部定理可定位。区分原文已证明步骤、引用输入、条件性结论与未解决缺口；不把待证性质藏入定义。为关键构造说明良定义或存在性依据，缺失时交数学更正而非编造。

这些内容保持普通数学表达，不要求文章写作时选 Lean 表示或写代码，不把基础库缺失设为文章发布障碍。按需进入 [formalize-research](../formalize-research/SKILL.md) 后，再绑定文章结果与 Lean 声明、工具链和验证记录。先提取并轻量审核相关数学地图，再复用其结构建立 Lean 蓝图；局部目标只需局部地图。新数学须经原增量审核；形式化辅助引理不因产生于代码就自动进入事实文章。
