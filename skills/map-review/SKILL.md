# 独立地图忠实性审核

先定位用户的事实工作区 ROOT。本项目为项目根下的 `facts/`。读取 ROOT/workspace.json；schema 必须为 `math-workspace/v1`。使用其 runtime 相对 ROOT 解析脚本绝对路径 FLOW，运行 `python3 FLOW ROOT status`。遵循 [文章优先接口合同](../shared/ARTICLE-WORKFLOW.md)。不从无关状态文件推断数学内容，不使用未经核验的脚本回填状态。工作区尚未配置时调用 initializing。

输入是合同 article-map-review-packet/v1，包含冻结文章、地图、来源检查与验证记录。禁止要求旧 projection.json、canonical state 或 to-map freeze-projection。文章是唯一内容依据，不把旧地图当 Gold。理解环节整理的结果目录和证明结构只作阅读索引，不充作审核通过证据。

轻量执行：先读验证记录与变化索引，按主要结果及其直接证明链对照文章；新增/变化对象在这次阅读中一并完成条件、分类、来源与覆盖核对，避免按多套清单反复阅读同一材料。合格项只写能定位检查依据的简短理由；旧项复用适用评估，详细解释集中在具体遗漏、条件失真和错接依赖。首次图仍检查全部未审核范围，不能用用户已经理解代替来源核对。无需重审数学证明正确性、重建蓝图或另写长篇全文评审。

使用未参与本次地图提取或修图的真实原生 reviewer；曾参与文章写作本身不排除其对照原文审核提取。Main 按本次工作补充需回避的参与者，默认 Sol/medium。先读包内 review-focus.json（旧包没有时由 Main 提供准确比较材料），并按 [Entry 含义与提取质量](../to-map/references/entry-quality.md) 判断分类、条件和粒度。

默认审核新增、修改的 Entry/Inference，以及变化的 B0、否定对和受影响的旧对象。对每个本次范围内的 Entry，同时核对来源与读者能否理解、引用：条件与结论是否完整，标题声称的内容是否落实，Definition 是否确实定义对象或数据类，是否把证明残句或研究评论当作陈述。可阅读准确引用的共享背景，不要求节点重复所有定义；不要仅因文字取自原文就给出通过理由。问题写到具体内容，合格项可简洁说明，不新增逐条问卷。对照文章新增、修改部分反向检查漏提；原文删除的内容也要检查地图是否仍错误保留。依赖、共同假设或符号变化时沿实际影响扩大范围，索引列出的相邻对象只是阅读提示，不是完整语义影响判定。全文与全图可随时查阅，不要求每轮重读未受影响部分。

previous_review 提供可核实的旧独立审核、文章和地图。确认旧结论适用后，复用未受影响对象和章节的评估；旧 ID 相同或对象文本相同本身不够，源上下文和依赖也须未改变含义。复用项注明旧报告位置、哈希及所引用对象/章节，来源行号移位时更新到当前文章。可以用脚本合并旧评估与本次新评估，不让 reviewer 重新撰写所有旧理由。

首次建图、没有适用的独立旧审核时检查尚未审核的全部范围；整体重构或系统性问题按实际影响扩大，必要时全文审核。修图复审同样聚焦修复及影响，未通过报告中的明确已核对部分可以有依据地引用，但不能把旧报告的整体拒绝改写成整体通过。原文覆盖必须独立沿源变化检查，不能因地图对象全部打钩就宣称无遗漏。source_coverage 保留当前章节对应对象或未提取理由，区分本次检查与旧审核复用；来源没有的证明不能补造。

对本次受影响的主要证明链，从主要结论回查必要中间结果，再核对各步直接前提、适用条件和论证方向；不为连通地图补造桥梁，不把条件性蕴含改成无条件箭头。此检查属于现有依赖与覆盖审核，不新增审核阶段。

按合同 10+45+45 评分并产出逐对象 verdict。全量覆盖记录由本次核对与有依据的旧审核复用合并形成，不表示每轮重新全量审核；在报告 summary 简述本次范围和复用依据。按合同导入真实原生 rollout 和回执，明确所有遗漏、失真、虚构和未解决项。100 分且全部项忠实、sourceClean、coverageRatio=1、问题列表为空才通过。来源记录必须满足共享合同中的定位、对象引用及全文范围覆盖校验；未提取范围写明理由。100 分表示本次提取审核通过，不是数学正确性的百分百保证。机器只验证绑定和显式记录，不证明语义忠实性或未遗漏；结论必须来自真实独立对照。

区分需要修复的内容问题与可选表达建议，按 Entry 质量指导记录。缺条件、缺结论或虚设定义等问题进入既有问题列表；篇幅、可删的重复解释或合理的另一种编排只写入 summary/报告正文的建议，不因此扣分或阻塞发布。100 分表示满足本次审核要求，不代表没有任何润色空间。不添加字数、重复率或节点数量门槛。

投影问题先交 Main，由 Main 按原文优先局部修复，必要时调用 to-map；保存新地图 ROUND，原独立 reviewer 优先复核变化与实际影响，复用仍适用的已审部分。仅有可选建议可直接通过，不强制再修一版。文章疑点由 Main 判断局部修订或路由新推理，不在地图审核中改数学。通过后交 Main 按文章接口 publish 地图，不重新启动文章维护。地图修订不增加研究轮，不再次接纳数学。

若只审核当前初始化地图或修复当前文章的提取，用合同 map-packet --current；工具保留已知文章作者来源，Main 补充本次提图或修图参与者的回避身份；不要求 Commit。通过后同修订发布，不能凭地图审核接纳数学。

调用方按 [轮次合同](../shared/ROUND-WORKFLOW.md) 用原生完成通知或有界等待接收结果，完成后 Main 立即继续，不默认等 15 分钟 heartbeat。审核者保持只读候选、只写报告；恢复先查实际已完成审核，避免重复派审。
