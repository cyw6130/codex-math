# 单次数学研究

## 显式入口与执行边界

仅在用户使用 `$advancing`、指定本技能，或明确说“用 advancing”时执行。用户仅说“继续研究”“推进一下”不构成显式调用；其他 skill 不自动调用本技能。用户已显式启动的未完成任务可按原授权恢复，不反复要求重新调用。

advancing 与 run-math 是平行研究入口：本技能由 Main 在当前任务执行一次有边界的研究；run-math 使用 Codex 证明 session 调度有预算的多轮研究。两者仅复用文章、归档与审核接口，不相互作为子流程。本技能不要求 Codex 证明 session 池，不创建 Codex session 派发台账、round.json 或研究 heartbeat，不消耗、重置或恢复 run-math 预算；需要转为 Codex session 多轮研究时先取得用户选择，不能静默切换执行者。

## 确认任务与恢复上下文

读取 [文章接口](../shared/ARTICLE-WORKFLOW.md)；[轮次合同](../shared/ROUND-WORKFLOW.md) 中的事实来源、研究讨论、独立审核及更正规则适用，Codex session 专用派发、轮次计数和自动提交策略不直接套用单次任务。

运行 status，核对真实文章与接纳收据，已有 pending 或 repair 先按文章接口恢复。未初始化时交 initializing 处理基线，不凭空创建已接纳事实。读取目标相关材料、已有理解记录、失败尝试和未决问题；从理解完成或地图完成处都可继续。地图仅作带版本的导航，缺失或滞后不阻塞研究；事实前提以最新有效文章及收据为准。

复用用户已明确的目标、范围和约定。仅给入口而目标不明时，实际读取并遵循 grilling，与用户确定一个问题及本次完成边界；不要求用户先给猜想，也不重复盘问已确认事项。重要新发现或原则性目标变化按研究讨论规则处理。一次任务结束后不自动另开研究任务。

## 冻结基线并执行研究

在开始实质推理前按文章接口调用 `start`，一个任务对应一个 Attempt。冻结准确文章、地图、真实目标交互及必要来源；保存作者身份和本次范围，不能事后补造轮初基线。

Main 执行所选问题的推理、必要检索或计算，保存实际可见的数学推导、工具输出、引用与失败尝试。明确区分证明、条件性论证、计算证据、猜想和启发，不编造隐藏推理或工具成功。需要额外执行者时遵循当前用户授权和适用委派规则，不默认创建子 Agent 来替代本入口的执行；独立数学审核按下文既有合同进行。

达到任务边界或出现无法继续的具体阻塞时，整理一份任务总结：原目标、实际尝试、可靠结果、失败及排除、剩余缺口。用户停止时保留真实完成范围。

## 默认归档；显式 Commit 后审核与更新文章

有可审核数学增量时调用 prepare-math-increment，基于冻结文章准备局部增量，不先重写完整事实文章。用 `finish` 归档 candidate/no_change/failed/interrupted，完整数学证据和总结逐个作为 evidence 保存；不伪造 Codex session closure 或任务返回记录。未完成任务不把部分结果冒充完整候选。

可由用户显式调用多次 advancing 后再统一 Commit；次数不固定，一次后也可请求接纳。各次单独冻结基线与归档，未接纳候选只能作为明确标注的探索材料，不能当作无条件已证前提。批量接纳前核对来源版本、依赖、重复与冲突；不能直接合并时按文章接口形成保留原始证据的合并修订，再独立审核。

默认在 finish 后保留候选并进入共同理解，不调用 commit-research、接纳审核、accept 或 maintain-math-article，不更新事实文章。prepare-math-increment 仅负责准备候选；其下游 Commit 交接在本入口默认不执行。选定研究问题或研究范围不等于请求接纳，不继承 run-math 的 per_round_auto 或一般项目自动提交设置。

只有用户明确说“Commit/接纳这次结果”或在本次任务请求中明确要求研究后 Commit，才调用 commit-research，按文章接口的普通 prepare 路径交独立 fact-increment 审核，取得真实回执后 accept，再由 maintain-math-article 发布完整文章并同步事实索引。该明确请求可在研究前或研究后给出，已给出不重复确认。默认收尾说明候选未接纳及保存位置即可，不把请求 Commit 设成必须回答的收尾问题。无增量不做空 Commit。

审核问题先由 Main 分诊与修订，再按共享合同独立复核；数学通过后才维护正式文章。局部修订属于原任务收尾，不增加 Codex session 轮次；需要持续新研究时说明剩余问题，不无限扩展本次范围。

## 共同理解与后续选择

独立任务收尾后调用 [understand-research](../understand-research/SKILL.md)，先回顾原目标，再梳理结果、条件和证明机制。用户已明确请求本次 Commit 时先完成审核接纳和文章发布；未接纳候选、中断或无增量如实说明。用户停止交流时保存继续位置，不继续提问。

不自动建图或形式化。用户选择后，数学地图经轻量 map-review 核对，再按需扩展为 Lean 蓝图；局部形式化只需相关局部地图。用户可停在理解或地图完成处。之后只有新的显式 advancing 调用才开启下一次单次研究；用户选择 run-math 时交给该平行入口核对目标与预算。
