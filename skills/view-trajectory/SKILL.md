# 查看真实研究历程

从项目配置确定实际 facts 目录，运行本技能的 `scripts/open_view.py --facts-root FACTS`。保持服务运行，用 Codex 侧边浏览器打开返回的本机 URL。默认展示原有图形时间线、对象详情与研究过程面板；不改成自制网页或仅给 Markdown。需要机器输入检查时加 `--export-json`。

本套装复用 Skill OS 1.12.0 的图形页面、画布、时间线和过程面板，原始资产与哈希保存在 `vendor/trajectory-reader`；本套装在 `runtime/trajectory-assets` 保存画布、侧栏与样式的局部修订，概览隐藏标签、缩放达到 2.2 后显示，黄色由准确的地图增量驱动；文章档案适配器在套装 `runtime/trajectory_view.py` 与 `tools/project-article-trajectory.mjs`。移动/分发时保留整个套装目录结构。

先校验冻结 Attempt、轮次总结及原始 Evidence。图形步骤读取真实 `base-map.json`（标为“轮初基线”）以及绑定已发布收据和独立审核的结果地图（标为“已发布地图”），地图版本取真实来源文章 revision。结果图相对发布前地图计算新增 ID；首次发布以对应冻结基线比较。黄色表示本次地图新增对象和所属推理连边，旧文章补录也可能新增地图对象，不能据此宣称数学是本轮新发现。基线不标新增；无比较依据时明确提示而不猜造。未变化对象复用显示身份，陈述修订保留各版；只修改已有 ID 不冒充新增。结果图尚待发布时显示待办，不以基线冒充结果，也不还原未归档的中间推导。原始文件可在过程面板展开，保留来源路径和哈希，不从全文猜造用户/Codex 证明 session分段。Commit 状态沿用真实审核收据校验；没有新研究轮绑定的本地 Attempt 也展示真实请求与 Commit，不为显示提交而虚构轮次；文章再次整合核对时显示文章待完成。当前已发布图交给 view-map 查看。

显示全部已归档轮次，包括 no_change/failed/interrupted。关联修订保留原请求与更正 Commit；Main 修订标为本地后处理及修订基线，有真实 round 绑定的 Codex session 修复才显示研究轮，不能按 Attempt 数量推算轮次。没有图的运行显示缺图提示，仍可查看过程；哈希错误或档案损坏必须报错，不能跳过后声称历史完整。空历史明确提示尚无记录。读取期间出现变化时提示重新打开，保持当前回放位置。

只读、不发任务、不接纳成果、不写锁或研究文件。底层不创建旧 Kernel State、Snapshot、Route 或治理收据。诊断或明确要求文本输出时才使用套装 `runtime/view_data.py FACTS --kind trajectory --format markdown`；这是辅助档案索引。

## 数学名称与详情

命名和公式渲染复用当前 view-map 所调用的 CMath-math-map：`vendor/math-map-display` 保存命名 v2、GammaMath、consumer 适配器及本地 KaTeX/字体，来源与哈希见其中 provenance.json。名称为“类型 · 编号 · 数学短名”；推理以结论的数学短名命名。文章章节标识保留在来源区，不作为地图编号。当前无持久命名账本的旧档案按冻结历史重建显示编号，同一原始对象 ID 在翻步、修订及末尾追加时沿用已有编号；不写入研究数据，也不冒称这是项目永久编号或保证与独立当前图分配的数字相同。

侧栏优先展示名称、准确原陈述、可点击的直接推理和后续；原题名与原始 ID 收进“来源与标识”。不展示内容版本哈希作名称；不在阅读器中改写数学陈述。段落、标题、列表及显式数学公式保留层次；长公式横向滚动。研究总结用相同排版，原始档案保持原文展示。黄色新增和缩放前隐藏标签继续有效。
